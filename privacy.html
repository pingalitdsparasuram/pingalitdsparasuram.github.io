Privacy Policy

Last updated: 25 November 2026

Burp & Beep Autopilot ("the app") is a private tool used only by the owner of the Burp & Beep YouTube channel. This policy explains what data the app uses.

What the app accesses

When the channel owner signs in with Google, the app receives permission to use the YouTube Data API and YouTube Analytics API for the owner's own channel only. It uses that permission to:

  • upload and schedule the owner's own videos and set their thumbnails;
  • read the owner's own video list and statistics (views, watch percentage, likes, shares, subscribers gained);
  • update the titles of the owner's own videos.

Where data is stored

The sign-in token and the statistics reports are stored only on the channel owner's own computer. Nothing is stored on any server run by the app.

Sharing

The app does not sell, share or transfer any data to anyone. It does not use data for advertising and does not access any other user's account.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Data deletion

Statistics reports are kept for at most 12 months and then deleted. The channel owner can delete all stored data at any time by deleting the app's folder; the stored sign-in token is deleted at the same time.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the files in the app's folder on the owner's computer deletes all stored data.

Contact

Questions: contact the Burp & Beep channel through its YouTube "About" page.
